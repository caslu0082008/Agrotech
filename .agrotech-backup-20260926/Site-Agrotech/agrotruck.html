Olá, produtor. Vamos conectar seu Agrotruck.

Siga os passos abaixo para colocar seu Agrotruck online. A conexão acontece direto entre o seu celular/computador e o robô — o site apenas te guia até lá.

Conta AgroTech: conectada
Wi-Fi do Agrotruck: verifique manualmente
Agrotruck: não verificado
Passo a passo
Como conectar

Estas três coisas são independentes: estar logado neste site, estar conectado ao Wi-Fi do robô e o Agrotruck estar respondendo. Uma não garante a outra.

  1. 1
    Ligue o Agrotruck
    Ligue a energia do carrinho e aguarde alguns segundos até o ESP32 inicializar por completo.
  2. 2
    Conecte-se à rede Wi-Fi do robô
    Abra as configurações de Wi-Fi do seu celular ou computador e conecte-se à rede abaixo. Essa conexão substitui temporariamente sua internet normal — é assim que o firmware do Agrotruck funciona.
    Rede (SSID) Agrotruck
    Senha agrotech4i
  3. 3
    Acesse o endereço do robô
    Já conectado à rede "Agrotruck", abra o endereço abaixo no navegador do seu dispositivo.
    Endereço http://192.168.4.1
  4. 4
    Abra o painel de controle
    O painel com direção, modo automático e os sensores (umidade do solo e sensor de cor) roda direto no próprio Agrotruck. Por segurança dos navegadores, este site (HTTPS) não consegue puxar esses dados para dentro dele — por isso o painel abre em uma aba separada, apontando direto para o robô.
Pronto para abrir o painel?
Só funciona se você já estiver conectado à rede Wi-Fi "Agrotruck" (passo 2).
Abrir painel do Agrotruck

Este site está em HTTPS, então o navegador bloqueia essa checagem automática mesmo com o robô ligado (é uma proteção do próprio navegador, não uma falha do Agrotruck). Use o botão "Abrir painel" para confirmar diretamente.

Perguntas comuns
O botão "Abrir painel" não carrega nada

Confira se o seu dispositivo está mesmo conectado à rede Wi-Fi Agrotruck (não à sua rede de internet normal) e se o robô está ligado. O painel só existe dentro dessa rede.

Por que o site não mostra os sensores aqui mesmo?

Este site roda em HTTPS. Navegadores bloqueiam, por segurança, qualquer tentativa de uma página HTTPS buscar dados de um endereço local HTTP como o do Agrotruck — mesmo estando na mesma rede. Por isso o painel abre separado, direto no robô.

Meu celular perde a internet quando conecto no Agrotruck

Isso é esperado: a rede do Agrotruck não tem acesso à internet, então seu celular pode alertar sobre isso. Você pode reconectar à sua rede normal a qualquer momento para voltar a usar o restante do site.
